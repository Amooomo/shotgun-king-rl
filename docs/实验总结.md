# relative_v4 实验总结（seed 42）

> 配置：`reward=shaped_v2`，`action_mode=pruned_shots`，`layout_mode=random_medium`，
> `feature_mode=flat`，`geometry_mode=relative_v4`，`seed=42`，`300k timesteps`。
> 唯一研究变量：`relative_v2 → relative_v4 (v2 + immediate move danger)`。

## 1. 结论

`relative_v4` 显著优于 `relative_v2`：

| 指标 | relative_v2（多 seed 参考） | relative_v4 seed42 |
| --- | --- | --- |
| Win | ≈ 58% | **74.5%** |
| Death | ≈ 41% | **25.3%** |
| Timeout | — | 0.2% |

- Independent 1000 episodes：**Win 74.50% / Death 25.30% / Timeout 0.20%**。
- Callback 300k best region 稳定在 72%～77%。
- 落在任务预设的「显著提升」区间（Win ≥ 63~65%，Death ≤ 35~37%）内。

## 4. 解读

- MOVE 占比高、命中率恒为 100%（pruned_shots 语义），因此 hit rate 不再是重点。
- 死亡局平均长度明显更短（4.64 vs WIN 7.07），说明残余死亡多为早期/激进操作。
- Immediate movement safety 有效缓解了一部分「合法移动但立刻进入白棋攻击范围」的死亡；
  剩余 Death 更可能来自 **enemy reply risk**（敌方行动后才致死），符合任务第 20 节推断。
